# 小晴 · 角色设定与图像生成提示词（完整版）

> 用途：生成「心晴伙伴」吉祥物小晴的官方形象（图案/插画/表情包/贴纸）。
> 配套：`frontend/src/app/page.tsx` 的 XiaoQingClay 占位 SVG、`docs/design/心晴伙伴-前端设计规范.md`。
> 任何一张官方图定稿后都可以发给我改建成分层 SVG 动画（见文末说明）。

---

## 一、角色档案（给画师的"人设"，给 AI 的 soul）

- **名字**：小晴（XiaoQing）——谐音"心情"，也取"天晴"意：再阴的心情也会放晴。
- **身份**：心晴伙伴（青少年心理护航系统）里的 AI 心理伙伴。TA 不是医生、不诊断、不打分；
  TA 只做三件事：**陪你聊、接住你的情绪、在你需要时把求助信息递给心理老师。**
- **性格**：温柔、耐心、有点笨拙的可爱；不催促、不评判；说话短而轻，永远先接住情绪。
  口头禅参考："慢慢来，也算数。" "不着急，我陪你。" "告诉老师一下下，好不好？"
- **年龄感**：无年龄。中性、无性别侧向，10-18 岁学生都觉得"像同龄朋友，不是大人说教"。
- **禁忌（角色纪律 = 产品纪律）**：不穿白大褂、不听诊器、无针头/药片等医疗符号；
  不用"有问题/不正常/抑郁"这类词；不下结论指向孩子的内心状态。
- **核心视觉记忆点（三种都画也要一致）**：
  1. 云朵状的身体（软软的、像一小朵天上的云）
  2. 双手永远捧着一颗小桃心（#E95445 珊瑚红）
  3. 木质小牌子写着「慢慢来也算数」

## 二、视觉风格（一句话 + 展开版）

**一句话**：黏土拟物 × 卡通治愈贴纸——"奶油纸上的软软小云朵，像捏出来的，不是画出来的。"

**展开版（每次生成都带上）**：
- claymorphism 黏土 3D 质感：整体像软陶/黏土捏出来的圆润形体，浑圆无尖角，
  表面有柔和的次表面光（光从体内微微透出来的感觉），边缘务必膨润带一点"捏出来的弹性变形"。
- 光照：单一大而柔的光源（左上），高光呈柔和的窗口状或斑点状；阴影暖灰不脏、无锐利投影边。
- 描边：整体带极细的同色系深色轮廓（近似 2.5px 墨色收边），贴纸切割感。
- 背景：奶油纸底 #FFF6EC（或透明底 PNG），可有极淡的圆点纹理，色调永远偏暖偏粉。
- 呈现形式：单一角色居中，全身或 3/4 身，贴纸式的完整轮廓，不做场景叙事图。

## 三、精确配色（直接抄，命名即语义）

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 云朵体色（受光面） | `#FFFEFB → #FCF7EC` | 中心向外的奶油白 |
| 云朵体色（暗部） | `#EFE3D1` | 暖燕麦灰，不用冷灰 |
| 桃心（捧在手里的） | `#FF9C8E → #E95445` | 珊瑚红渐变，唯一允许的"暖渐变" |
| 腮红 | `#FFC9BC`（或 `#FFB5A7` 加透明度） | 圆椭圆，两侧对称，可削弱暗部 |
| 眼睛/线条/木牌字 | `#2A2320`（"墨色"，禁纯黑 #000） | 2.5px 视觉粗细 |
| 眼睛高光点 | `#FFFFFF` | 每只眼 1-2 个小亮点 |
| 微笑线 | `#2A2320`，圆头笔触 | 浅浅的、向上的软弧 |
| 太阳（场景道具） | `#FFE9A6 → #F5CD55` | 柠檬黄 |
| 小云朵（场景道具） | `#EFF7FF → #D8EAF9` | 天蓝 |
| 草地（场景道具） | `#9ADBC0`（薄荷） | 操作/行动色 |
| 木牌 | `#D9B98A` 底 + `#8A6B45` 边框 | 圆角矩形，绳挂在云上 |

**强调色语义（同屏分工，沿用全站规则）**：薄荷 `#7FDBB6`=行动/按钮；蜜桃 `#FFB5A7`=温柔/标签；
柠檬 `#FFD66B`=提示；天蓝 `#A9C9DE`=中性信息。危险态 `#EF6A63` 只出现在"寻求帮助"通道上。

## 四、外形细节清单（画师逐条核对用）

**头身（云朵小晴·主形象）**
- 一朵矮胖软云：底部是宽圆的云盘（宽略大于高，总高宽比 ≈ 1:1.1），上方两三个圆润云苞错落；
  所有弧线连续、无内凹尖角。
- 无脖子、无腿；"脚"是云底两个圆形凸起云泡，走路时一颠一颠。
- 比例：眼位在头部纵向约 45% 高度，两眼间距 ≈ 0.8 个眼宽。

**五官**
- 眼睛：两颗竖椭圆实心墨点（`#2A2320`），下缘微圆；各带 1-2 个白高光点（左上为主）；
  眨眼/温柔注视时可变成弯月形（"n"形单线，圆头端点）。
- 眉毛：默认无（更干净）；安慰场景时可加两条极短的浮空弯眉。
- 腮红：两片横向椭圆 `#FFC9BC`，透明度 85% 左右，位于眼下方外侧。
- 嘴：一条圆头短弧线，默认浅笑；说话场景可换成小圆"o"或"3"形猫嘴，禁止咧嘴大笑。
- 面部永远只有五官，不画鼻孔。

**手与动作**
- 两只圆润小手（同体色，掌侧 `#EFE3D1`），指节圆润不分离、不画指甲；
- 默认姿势：双手捧一颗 3D 软陶小桃心，心微微贴在胸口，像"捧水不洒"的谨慎感。

**配饰（可选项，择一出现，不要全堆上）**
- 胸前挂/云边插一块圆角木质小牌子，墨色手写感字：「慢慢来也算数」；
- 头顶一朵指甲大小的薄荷绿小芽（两片叶）——代表"在长出来的勇气"；
- 或一朵放在云边的小柠檬花。

**质感与描边收尾**
- 所有高光为柔白斑点/圆角条，禁止锐利 specular 星形高光；
- 轮廓收边：`#2A2320` 弱化到 60-70% 透明度，宽 2.5px 等效；
- 贴纸模式：整体外扩 8-10px 的一圈白色贴纸边（die-cut sticker），再压偏移硬投影 `#EFE3D1`。

## 五、表情与姿势九宫格（生成表情包用）

| 编号 | 状态 | 动作/表情要点 |
| --- | --- | --- |
| 01 | 默认陪伴 | 捧心浅笑，眼白高光，云微微起伏 |
| 02 | 倾听 | 身体前倾 5deg，眼睛变大 + 高光点上移 |
| 03 | 点头鼓励 | 云上扬、双手高举桃心过头顶，眼变弯月 |
| 04 | 安慰 | 一只手轻拍自己腮红处，头歪向一侧 |
| 05 | 悄悄话 | 双手拢在嘴边做小喇叭形，眼眯成线 |
| 06 | 难过共情 | 眼下垂 + 一滴小泪珠挂在眼角（不掉下来），云底微塌 |
| 07 | 递出求助 | 双手把桃心递向镜头方向（第一人称视角），眼认真 |
| 08 | 加油打气 | 头顶小芽抽高一点，双手握拳举在下巴旁 |
| 09 | 晚安 | 云朵收拢变矮，眼闭成两道弧，头顶月亮挂角 |

危机/求助表情（07）是产品关键动作：**心朝向"你"递出，而不是抱着自己**——
传递的语义是"帮你的那颗心给你"，不是"我自己难过"。

## 七、把一张图改成 SVG 动画（能！但看图选路线）

**能做，看你给的图走两条路线：**

1. **整体动（任何图都行，最稳）**：图片本身当作贴纸素材，我做 CSS 动画——
   浮动上下、呼吸缩放、微倾摇摆、点击下压回弹。保真 1:1，但属于"贴纸碰碰"，胳膊不会单独动。

2. **分层重绘（推荐，效果最好但有风格收敛）**：我照着你给的图，**手工重建成结构化分层 SVG**
   （云体/眼睛/腮红/双手/桃心/配饰各一层），然后做局部动画：眨眼循环、随消息呼吸、
   桃心跳动、小手挥手；描边、配色、质感会向本文档的贴纸规范收敛——不是像素级描摹，
   而是同一个角色用项目视觉语言重画。平涂/儿童绘本/卡通贴纸风的图效果最好；
   写实照片、厚涂重光影的图不适合拆层。

**保证兼容**：我会把分层的眨眼/浮空/心跳动画做成可直接替换现有 `XiaoQingClay` 组件的
React 组件（接受 props 控制表情），页面其余部分不动。

**给我图时最省事的规格**：透明底 PNG、人物居中占画面 ≥60%、单一姿势、平涂色块、
文字（木牌）单独清晰；如果你有多张不同动作的图，我就可以做出"多表情组件"而不是推测。
