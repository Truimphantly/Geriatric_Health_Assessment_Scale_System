# 心晴伙伴 · 前端设计规范（A 卡通治愈贴纸风）

> 版本 v1.0 · 适用范围：青少年心理护航系统全部界面（学生端为主，老师端为「同宇宙克制版」）
> 落地位置：`frontend/src/app/globals.css` 的 `:root`（老师端）与 `.patient-app`（学生端）作用域；样机参考 `design_mockups/a-full/`

---

## 1. 风格定位

**一句话**：像一本被认真做过的青少年情绪手账 —— 温柔、贴纸感、零压迫。

| 维度 | 设定 |
|---|---|
| 受众 | 10–18 岁学生（核心）、心理老师（管理端）、监护人（家长端） |
| 气质 | 「愿意听你说话的大朋友」，不是测评员、不是问卷、不是医院系统 |
| 视觉隐喻 | 贴纸本 / 手账 / 朋友聊天窗（**不是**医疗仪表面板） |
| 情绪目标 | 被接住、不紧张、可以慢慢来 |
| 反面 | 医疗蓝白、严肃表格、渐变科技感、AI 通用模板脸 |

**设计决策的来由**：青少年筛查的最大障碍是「抵触感和标签感」。视觉上先去医疗化，才能让学生愿意开口；因此风格承载的是产品策略，不是装饰偏好。

## 2. 设计 token（唯一事实来源）

### 2.1 色板

| 角色 | 值 | 用途 |
|---|---|---|
| 背景（奶油纸） | `#FFF6EC` | 全站底色；叠加波点纹理（见下） |
| 卡面 / 次级面 | `#FFFFFF` / `#FFF9F2` | 卡片、输入框、次级底 |
| 墨色（描边/正文） | `#2A2320` | **所有描边、硬投影、正文**。绝不用纯黑 `#000` |
| 主色·薄荷（行动） | `#7FDBB6` | 主按钮底色、进度填充、正向标记 |
| 主色·深薄荷（文字） | `#35A278` | 链接、强调文字、可访问性达标的绿 |
| 强调·蜜桃 | `#FFB5A7` | 贴纸标签底、共情/温柔语义 |
| 强调·柠檬 | `#FFD66B` | 荧光笔高亮、提示条、待办语义 |
| 强调·天蓝 | `#A9C9DE` | 中性信息卡、机器人形象底色 |
| 危险 | `#EF6A63` | 危机上报、错误态（配 `#FFEFEE` 浅底） |

**波点纹理**（唯一的"底纹"手法，纯色块实现，非渐变）：
```css
background:
  radial-gradient(circle at 3px 3px, rgb(213 180 138 / 18%) 1.7px, transparent 1.8px),
  var(--background);
background-size: 28px 28px, auto;
```

### 2.2 形状与光影

| 属性 | 值 | 说明 |
|---|---|---|
| 描边 | **2.5px** 墨色（`#2A2320`） | 卡通风的骨架；绝不用 1px 细线 |
| 硬投影 | `5–8px Npx 0 <墨色或专色>`（0 模糊） | 贴纸浮起的唯一手法；**禁用柔和阴影/发光** |
| 圆角 | 卡片 20–24px · 按钮/标签 999px（胶囊）· 输入 14px | |
| 贴纸倾斜 | `rotate(-3deg ~ 3deg)`，仅限标签/便签 | 老师端一律不倾斜 |
| 卡片内边距 | 16–24px | |
| 栅格 | 学生端 430px 手机框；桌面端 1080–1180px 居中 | |

硬投影示例：
```css
.patient-card      { border: 2.5px solid #2A2320; border-radius: 22px; box-shadow: 6px 6px 0 #2A2320; }
.patient-card-soft { box-shadow: 7px 7px 0 #7FDBB6; }   /* 进行中任务 */
.patient-card-sticker { border: 2.5px dashed #2A2320; box-shadow: 5px 5px 0 #FFD66B; } /* 便签 */
```

### 2.3 字体

```css
--font-sans: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', system-ui, sans-serif;
```
- **全部走本地中文栈，禁止外链字体**（离线演示环境的硬要求）
- 标题字重 **900**、`letter-spacing: -0.035em`；正文 400–600
- 教学语气的关键句用 `.patient-highlight`（荧光笔下划线，色块非渐变）：
```css
.patient-highlight { background: linear-gradient(transparent 58%, #FFD66B 58%); font-weight: 800; }
```

## 3. 组件规范（类名即规范，实现见 globals.css）

| 组件 | 类名 | 规则 |
|---|---|---|
| 贴纸卡 | `.patient-card` | 2.5px 实描边 + 6px 墨色硬投影 |
| 便签卡 | `.patient-card-sticker` | 2.5px **虚线**描边 + 柠檬投影（用于"等待/提示"语义） |
| 主按钮 | `.patient-primary-button` | 薄荷底 + **墨色文字** + 胶囊 + 4px 硬投影；hover 位移 −1px、active 下沉 +2px |
| 次按钮 | `.patient-outline-button` | 白底 + 2.5px 墨描边 + 胶囊，无投影 |
| 输入框 | `.patient-field` | 2.5px 墨描边 + 14px 圆角；focus 变深薄荷描边 + 换底色，**无发光** |
| 进度条 | `.patient-progress-track/value` | 14px 高 + 2.5px 描边 + 薄荷填充（胶囊） |
| 贴纸标签 | `.patient-sticker-tag` | 蜜桃/柠檬/天蓝底 + 墨描边 + 2.5px 硬投影 + `rotate(-2.5deg)` |
| 顶栏 | `.patient-topbar` | 奶油底 + **2.5px 墨色底边**（无毛玻璃） |
| 底部导航 | `.patient-bottom-nav` | 白底 + 2.5px 墨色顶边 |
| 语音球 | `.patient-orb` | 状态配色：聆听/说话=薄荷·思考/暂停=天蓝·异常=柠檬·结束=灰 |

**语音状态色映射**（保持语义一致）：
```
connecting / listening / transcribing → #4AAD8A（薄荷系）
thinking / paused                     → #6F9CC4（天蓝系）
speaking                              → #EF8D81（蜜桃系）
error / text_fallback                 → #E3A83C（柠檬系）
closed                                → #8B8378（灰）
```

## 4. 页面范式（学生端）

1. **三端门厅**（`/`）：小晴头像 + 三个入口贴纸卡（学生=薄荷 / 老师=蜜桃 / 家长=天蓝）+ 保密边界声明条
2. **学生登录**（`/student`）：小晴头像 +「学生入口」贴纸标签 + 任务号 + 证件后四位 + 柠檬提示卡
3. **任务列表**（`/student/tasks`）：标题「今天的小晴任务」+「没有对错题」贴纸 + 任务贴纸卡（进度胶囊 + "大约 10 分钟，随时可以停"）
4. **对话页**（`/student/dialogue/*`）：AI 气泡（白底墨描边，尾角左下）+ 学生气泡（薄荷底，尾角右下）+ 科普便签卡 + 危机横条（红色虚线）+ 麦克风停靠栏（薄荷圆角方块）
5. **情绪手账**：周格子贴纸 + 连续记录徽章 + 小晴周报卡

**文案纪律**（与视觉同等重要）：
- 学生端**不出现**量表名、筛查主题、诊断词（如"抑郁筛查量表""自杀风险"）
- 不用「评估/宣教/护患」等专业词 → 用「聊天 / 小卡片 / 老师 / 你」
- 危机相关一律「先接住情绪，再说行动」，并给热线（12356 / 12355）

## 5. House Rules（去 AI 味硬规则，逐条可检查）

> 来自 taste-skill 的方法论，按本风格适配。**违反任一条即视为不合格**。

| # | 禁止 | 替代做法 |
|---|---|---|
| 1 | 任何背景/按钮/文字渐变 | 纯色块，或便签底色 |
| 2 | 玻璃拟态、`backdrop-blur` 悬浮面板 | 实心奶油底 + 2.5px 墨边 |
| 3 | 1px 细线、发丝分隔线 | 2.5px 墨色描边，或留白/换底色 |
| 4 | 居中小字 eyebrow（"New ·"、上标小标签） | 信息写进标题或首句；需要标签用「贴纸标签」 |
| 5 | 图标卡片阵列（三列等高 icon card） | 贴纸卡 + 非对称内容 |
| 6 | 纯黑 `#000`、纯白文字压彩底以外的硬对比 | 墨色 `#2A2320` |
| 7 | 柔和阴影 / 发光 / 高斯模糊 | 0 模糊硬投影 |
| 8 | 等宽字体（非代码场景） | 中文栈 |
| 9 | 紫蓝「AI 渐变」配色 | 奶油+薄荷+蜜桃 |
| 10 | 标题超两行 | 砍字数，先改文案再改字号 |
| 11 | 装饰性渐变光斑、假仪表盘灰条 | 真内容或空着 |
| 12 | 两套以上字体 | 一套中文栈 |
| 13 | 大面积空白无内容的"高级感" | 贴纸卡承载实内容（信息密度要够） |
| 14 | 每屏都靠动效才成立 | 静态也要完整 |
| 15 | 硬编码医疗/老年语义（住院/病区/护士/患者） | 心理护航语义（档案/中心/老师/学生） |

**允许（本风格的表达手法）**：
- emoji 作为**内容性表达物**（情绪贴纸、状态图标）——后续可替换为官方素材图
- 小晴形象 SVG 占位（圆头机器人 + 腮红 + 天线），素材到手后替换
- 便签倾斜、贴纸虚线、荧光笔高亮

## 6. 老师端：同宇宙克制版

同一套 token，**去掉贴纸感、提高信息密度**：

| 维度 | 学生端 | 老师端 |
|---|---|---|
| 底色 | 奶油 + 波点 | 奶油（无波点或更淡） |
| 卡片 | 2.5px 描边 + 6px 硬投影 + 倾斜标签 | 2.5px 描边 + 4px 硬投影，无倾斜 |
| 标题 | 900 字重、圆润口语 | 800 字重、专业短语 |
| 数据 | 大数字 + 表情 | 数字突出 + 表格化 |
| 色彩 | 三强调色混用 | 薄荷主色 + 红/黄仅用于风险等级 |

实现上把 token 放在 `:root`，学生端在 `.patient-app` 内覆盖 —— 这样老师端 16 页自动继承"同宇宙"配色。

## 7. 自检清单（提交前逐条过）

1. `grep -rn "gradient" src/` → 只允许 `.patient-highlight` 与语音球内部着色
2. `grep -rn "backdrop-blur\|box-shadow: 0 " src/` → 0 命中（无玻璃、无柔影）
3. 所有卡片都有 `2.5px` 描边 + 偏移硬投影
4. 无 1px 边框（除表单/表格等真实控件）
5. 标题不超过两行（缩到 375px 宽检查）
6. 无外链字体请求
7. 学生端文案无「量表名/筛查主题/诊断词/护士/住院」
8. 危机路径可见且动作明确（上报 + 热线）
9. 老师端每屏信息密度足够（表格/列表承载真实数据）
10. `tsc --noEmit` 零错误
