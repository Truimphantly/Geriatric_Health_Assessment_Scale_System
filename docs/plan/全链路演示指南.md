# 心晴伙伴 · 全链路演示指南

> 适用版本：v0.4-safetyloop-report（风险台账 + 转介闭环 + 护航报告）
> 一句话故事线：**聊天中察觉危险 → 自动上升为风险档案 → 老师转介 → 家长知悉 → 护航报告三端同见。**

## 方式一：一条命令的脚本演练（适合台下快速验证 / 回归）

前置：后端(8000) 与 Celery 已启动（双击「一键启动.bat」即可）。

```bash
cd backend
uv run python -X utf8 scripts/full_loop_demo.py
```

脚本按 9 步推进：老师布置任务 → 学生登录 → 等 AI 首问 → 正常轮+危机轮对话 →
台账自动登记 → 老师处理呼叫 → 转介发起/家长知悉/完成结案 → 复核确认生成报告 → 三端可见性核验。
结束输出 16 项 OK/NO 清单，全 OK 即整链路健康。

## 方式二：真人点击演示（适合面向老师/评委）

按下面顺序点，全程约 8 分钟。学生用 **小诚**（任务号见第 1 步，证件后四位 2889），
家长手机号 `13900001111`、验证码 `123456`，教师工号 `N002 / 123456`。

| 步骤 | 端 | 操作 | 讲解点 |
| --- | --- | --- | --- |
| 1 | 教师端 `/teacher/tasks` | 新建任务，勾「AI 语音对话」，选小诚 | 老师只需要知道给谁聊，不布置题目 |
| 2 | 学生端 `/student` | 任务号进入 → 读心意卡 → 和小晴正常聊两句 | 像和豆包聊天，没有表格和题目 |
| 3 | 学生端（继续） | 危机演示句：「有时候真的觉得活着没什么意思，不想面对了。」 | 语气保持平静，展示系统如何接住 |
| 4 | 学生端 | 观察小晴的回应转缓和、给出求助路径 | 危机话术已内置，不靠模型自觉 |
| 5 | 教师端（弹窗/SSE） | 注意右上角紧急提醒弹入 | 无需刷新页面 |
| 6 | 教师端 `/teacher/risks` | 打开风险台账：高等级档案已自动登记，来源、学生原话节选都在 | 兜底与服务端留痕，不是一次性提醒 |
| 7 | 教师端 `/teacher/risks` | 点「发起转介」→ 选「校心理辅导室」→ 填去向与建议 → 提交 | 档案状态变「已转介」 |
| 8 | 家长端 `/guardian` | 手机号登录 →「转介跟踪」里看到去向/建议，留言并点「我已知晓」 | 家长看到的是"要做什么"，不是孩子原话 |
| 9 | 教师端 `/teacher/risks` | 转介卡片出现家长回复 → 点「确认转介完成」 | 档案闭环结案 |
| 10 | 教师端 `/teacher/tasks/[id]` | 「查看护航报告」→ 整体评估/量表小结/复核说明/建议 | 报告在复核确认瞬间自动生成 |
| 11 | 学生端：任务完成后 | 任务卡上出现「老师想说的话」 | 只有建议与署名，没有量表名/分值 |
| 12 | 家长端：刷新门户 | 「报告摘要」板块出现风险标签与建议 | 三端同一事实，口径不同 |

备注：若想完整展示分数，让学生把任务聊完（约 20 轮）再复核；只演示机制时，
脚本演练或两轮对话即可复核确认（报告会显示「待评估」，不影响讲解流程）。

## 演示数据与清理

- 台账/转介/报告全部为真实落库演示数据；演示前想「Reset」只需把 status 手动置 closed
  或按后端脚本新增一轮演练（新档案自动另开）。
- 学生的对话原文永远不会出现在家长端——家长端只显示事件摘要与需要配合的事项。
