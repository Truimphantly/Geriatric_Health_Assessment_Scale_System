# 小晴语音终端 · 联调指南（ESP32-S3 板子 ↔ 电脑大脑）

> 前置状态：电脑端语音服务器已部署完成并验证可启动（本文第 2 节）。
> 板子：ESP32-S3 N16R8（COM6，已连电脑 USB）。

---

## 1. 架构一句话

板子 = 耳朵+嘴；电脑 = 大脑。板子通过 WiFi 把语音流发给电脑上的语音服务器，
服务器做"识别 → 小晴思考 → 合成语音"，再发回板子喇叭播放。

## 2. 电脑端（已完成 ✅）

- 服务器位置：`老年评估系统\xiaozhi-esp32-server\main\xiaozhi-server`
- 启动方式：双击 `xiaozhi-esp32-server\启动语音服务器.bat`（黑窗口别关）
- 启动成功标志：日志打印三行地址：
  - `Websocket地址是  ws://192.168.215.177:8765/xiaozhi/v1/`
  - `OTA接口是  http://192.168.215.177:8003/xiaozhi/ota/`
  - （IP 以当天实际打印为准；板子和电脑必须连同一个 WiFi）
- 当前配置：识别=Qwen3-ASR（百炼）、合成=CosyVoice（百炼）、大脑=小晴人设 qwen-plus
- Windows 的 opus.dll 已放服务器目录（来自 Miniconda，勿删）

> 注意：板子联调当天，如果电脑换了 WiFi，`data/.config.yaml` 里的
> `websocket:` 地址要改成新 IP（可用 `ipconfig` 查 WLAN 的 IPv4）。

## 3. 板子烧固件（二选一）

**方式 A · 官方网页烧录（推荐，最简单）**
1. 用 Chrome/Edge 打开 https://xiaozhi.me → 控制台 → 设备 → 添加设备 → 在线烧录
2. 数据线连接板子，浏览器弹出串口选择 → 选 **COM6**
3. 板型选择：若无完全一致的型号，先试 `ESP32-S3` 通用/面包板模板（N16R8=16MB Flash+8MB PSRAM）
4. 点开始烧录，等进度条走完

**方式 B · 我帮烧**：跟我说一声，我用 esptool 命令行刷（需要固件 bin 文件）。

## 4. 板子首次联网

1. 烧录完成、重新上电后，板子会发出 WiFi 热点：`Xiaozhi-XXXXXX`
2. 手机或电脑连上这个热点 → 自动弹配置页（或浏览器访问 `192.168.4.1`）
3. 填入**家里的 WiFi 名 + 密码**（必须是 **2.4GHz**，5G 频段连不上）
4. 保存后板子自动重启并连 WiFi

## 5. 把板子指向"电脑大脑"（关键一步）

官方固件默认连 xiaozhi 官方云。要连我们自己的服务器：

- 若固件是**官方原版**：开机后连按 `BOOT` 键进入配网/服务器设置，把
  OTA 地址改为 `http://<电脑IP>:8003/xiaozhi/ota/`（烧录时可直接在网页烧录器里填 OTA 地址，最省事）
- 板子会从 OTA 拿到 `ws://<电脑IP>:8765/xiaozhi/v1/`，然后开始对话

## 6. 验证清单（板子联网后逐条过）

| # | 检查 | 预期 |
| --- | --- | --- |
| 1 | 电脑语音服务器窗口 | 打印 `WebSocket连接建立` / 设备上线 |
| 2 | 对板子说"你好" | 板子喇叭回答（小晴声线） |
| 3 | 服务器日志 | 能看到识别出的文字与 LLM 回复 |
| 4 | 说一句"我最近心情不太好" | 回复温柔接住情绪（小晴人设生效） |
