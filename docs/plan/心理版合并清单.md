# 心理版合并清单（老年底座 × SunnyMindBuddy 心理壳）

> 分支：`feat/psychology-shell`。本文档给两位同学对齐：哪些东西保留了老年系统的底层，哪些换成了心理业务壳，来自哪里。

## 一、保留的老年系统底层（功能链路，未动）

| 资产 | 位置 | 说明 |
| --- | --- | --- |
| 三智能体编排 | `backend/packages/medagent/` + `app/workers/` | Schedule 调度 / Dialog 对话 / Extraction 抽取，依赖方向 app → medagent 单向 |
| 语音链路 | WebSocket 语音网关 + Qwen Audio Realtime | 识别+生成+合成一体，server_vad 断句、打断、attach 单连接顶替 |
| Celery 三队列 | `app/celery_app/`（dialog/schedule/extraction） | 逐轮驱动智能体，事件经 SSE/WebSocket 推送 |
| 量表驱动导入 | `app/commands/import_assessment_catalog.py` | 量表 = JSON 数据文件，幂等导入，仅"已发布"量表进入对话 |
| 前端患者/医护壳 | `frontend/src/` | 16 医护页 + 患者对话页，Next.js 16 + React 19 |
| 部署脚本 | `启动全部服务.bat` / `停止全部服务.bat` | PG16 + Redis8 + uvicorn + Celery + 前端一键启停，密钥读注册表 |

## 二、更换为心理业务的壳（来自 SunnyMindBuddy 与本项目新增）

| 业务壳 | 来源 | 落点 |
| --- | --- | --- |
| 3 份心理量表（PHQ-A 9题 / GAD-7 7题 / ASQ 4条） | SunnyMindBuddy `docs/structured/scales/` 结构化为本项目量表 JSON | `docs/structured/assessment-scales/{phq-a,gad7,asq-crisis}.json`，`index.json` 登记 |
| 心理科普材料（情绪/焦虑/低落/睡眠/压力/自伤 6 类） | SunnyMindBuddy `_PSYCHOEDUCATION_MATERIALS` 改为数据库教育材料 | 迁移 `20261013_psychology_domain.py` 幂等写入，`get_education_material` 工具读取 |
| 对话人设「小晴」+ 青少年面谈规范 | SunnyMindBuddy dialog prompt 同构重写 | `medagent/agents/service_agent/dialog_agent/prompt.py`（CICARE → 青少年心理评估面谈规范 6 步） |
| 危机事件约束词库 v2.0 | 本项目 keyword_library 重写（自杀/自伤/欺凌/侵害/绝望 + 学业/睡眠/求助） | `app/data/keyword_library.json` |
| 监护人知情同意文书（评估/联系监护人/数据使用/转介） | SunnyMindBuddy `_GUARDIAN_CONSENT_DOCUMENTS` | `dialog_agent/tools.py`（工具名沿用本项目三工具，接线不变） |
| 危机上报语义（通知心理老师） | SunnyMindBuddy `notify_teacher` → 本项目 `request_nurse_assistance` | `requested_action=notify_counselor`，医护端人工介入流程不变 |

## 三、跨域提示词已全部换岗（本轮新增修复）

开场白口吻由**调度智能体**和**对话运行器**共同决定，三处已同步心理域：
- `schedule_agent/prompts.py`：身份/排序原则（信任→日常→轻度症状→情绪→敏感条目收尾）/偏离检测例句（游戏攻略闲聊）/few-shot 四场景（含危机信号场景）
- `app/workers/dialog_agent_runner.py`：首问提示词（小晴人设+保密例外）与收尾提示词（感谢信任、心理老师复核、求助出口）
- `dialog_agent/prompt.py`：危机升级规则补强——明确自伤/自杀表述**当轮原生抽入** `request_nurse_assistance`，不等学生同意

## 四、端到端验证记录（2026-10-14）

1. 单元测试 250/250 通过。
2. 文本 E2E（`backend/scripts/e2e_psych.py`）：医护登录→建学生（15 岁小婷）→挂 PHQ-A/GAD-7/ASQ 任务→开场白为小晴口吻→患者登录（任务号+证件后四位）→学业压力回复→抽取 9 项落库→危机句→升级语义回复→"你联系吧"→工具上报 `need_manual_intervention=True`。
3. 危机当轮上报演练（15 岁小诚，PHQ-A+ASQ）：明确自杀意念表述后 12 秒内任务标记需人工介入，前端对话页同步出现"AI 工具呼叫护士"卡片（请求编号可查）。
4. 浏览器核验患者端：心晴伙伴登录页→任务列表（干预原因可见）→对话页（小晴头像/开场/消息流/SSE 已连接/13 项记录面板/语音按钮）。
5. 语音对话待用户按麦克风实测（链路与老年版共用，本轮未改语音栈）。

## 五、已知调优项（不阻塞演示）

- 抽取侧频率归因偏松：压力轮"有点睡不好"被抽为 q3=几乎每天、"有时候"被抽 q9=几乎每天；可在 extraction 提示词加"模糊频率不得取最高档"。
- 患者端文案仍是护理域：「进入护理服务」「我的护理任务」「入院评估任务包」「住院助手」「本次住院」等；干预 reason 原文（含自伤原话）直接展示给学生，建议换温和转述。前端美术大改时一并处理。
- 医护端任务包名沿用老年默认名，见表未见心理速览。

## 六、启动方式

双击根目录 `启动全部服务.bat`（需已 setx 的 `DASHSCOPE_API_KEY`），医护端 `http://localhost:3000/nurse/login`（N001~N005 / 123456）；患者端 `http://localhost:3000/patient` 用身份证+手机号登录（演示数据为合成档案）。E2E 回归：`cd backend && uv run python scripts/e2e_psych.py`。
